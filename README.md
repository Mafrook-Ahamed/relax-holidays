# Relax Holidays
Premium, responsive travel website for Relax Holidays, Trichy.

## Stack
- React 18 + Vite
- Lucide icons
- Responsive custom CSS and animation
- No database required for initial marketing and enquiry website

## Run locally
```bash
npm install
npm run dev
```
Build with `npm run build`.

## Flights
Flight search opens Google Flights in a new tab with route, dates, passenger count and cabin selections. It provides access to current external fares, rather than inventing prices. It is not an embedded airline booking API. A fully integrated flight offers experience requires production API credentials from a provider such as Duffel or Amadeus and a server-side backend. Never expose API secrets in browser code.

## Enquiries
The booking form sends enquiry details via WhatsApp to Relax Holidays. It does not confirm or charge for a booking.

Business information and package categories are based on the company's public website: https://www.relaxholidaypackages.com/
